# About Information Contract

Related Issue: #151

- Version/build、Applications/Frameworks、major Packages/Libraries/versions、License/Copyright/Attribution、official linksをread-only表示対象とする。
- Windows / Androidは同一情報契約を使用する。
- 情報源は実装時に既存build/package/license管理を横断調査してSoTを決定し、手動重複管理を避ける。
- Runtime status/diagnosticsや設定変更責務を追加しない。
