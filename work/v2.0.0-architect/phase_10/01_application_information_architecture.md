# v2.0.0 Phase 10-A — Application Information Architecture

## 日本語

### 前提
Phase 0〜Phase 9が完了し、Phase 9 Temporary Navigationが撤去済みであること。

### 目的
完成した全Applicationを基準に、Portal / Drawerで共通利用するInformation Architectureを確定する。

### 対象
- Application表示名
- Application description
- Group / category
- 表示順
- Primary / Utility / Administration等の役割
- Portal / Drawerで必要となる共通情報

### 原則
Framework名は実装情報であり、ユーザー向けApplication名と分離する。旧DRAFTやPhase 9仮導線をそのまま正式IAへ昇格させず、実装済みApplication全体を見て決定する。

### 完了条件
Portal / Drawerの正式実装に利用可能な一貫したApplication IAが確定していること。

---

## English
Define the final application information architecture after all Phase 9 applications exist and temporary navigation has been removed. Establish user-facing names, descriptions, groups, ordering, and roles. Keep framework identity separate from user-facing application identity. Do not promote temporary Phase 9 navigation into the final IA without review.
