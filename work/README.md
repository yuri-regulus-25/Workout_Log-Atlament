# work

`work/` は、設計・実装・検証の途中成果物、リリース計画、調査記録を置く作業領域です。

## 命名方針

GitHub Mobile App での閲覧互換性を考慮し、**ファイル名・ディレクトリ名は原則として ASCII の英語名を使用します。**

文書本文は日本語を基本とします。技術上必要な固有名詞・API名・コード識別子は英語のまま扱います。

## 主な領域

- `vX.Y.Z-plan/`: 各リリースの計画資料
- `design-audit/`: 設計横断監査、設計と実装の差異整理
- `ui-ux-review-through-v2.1.0/`: v2.1.0以前を対象に実施したUI/UXレビュー資料
- `v2.1.0-UT.md`: v2.1.0 UT本体
- `v2.1.0-UT-investigation.md`: v2.1.0 UT調査記録

`work/` の内容は、そのまま恒久的なAs-Is設計のSource of Truthにはしません。リリース・設計確定時に必要な内容を `docs/design/` へ反映します。
