# FX-12 Initial Setupステータスカードの縦幅圧縮

## 概要

Application SettingsのInitial Setup内にある4枚のステータスカードについて、情報量に対して過剰な縦幅を縮める。

## 確認した現状

確認画像: `Codex 画像 2026年9月2日 01_09_33.png`

対象は次の4項目。

- リポジトリ情報
- GitHub Token
- リソース
- データ同期

各カードは実質「アイコン + タイトル + 1行説明」程度だが、上下余白・高さが大きく、Initial Setupセクション全体を縦方向へ膨らませている。

## 034.mdからの訂正

034.mdでは一度「4列を2×2へ変更する」案が提示されたが、035.mdでユーザーから明確に否定されている。

**横方向の4カード配置を変更する要求ではない。**

したがって2×2化は採用しない。

## 確定している要求

- 現在の横方向4-card layoutは維持する。
- カード内部の不要な上下余白を削る。
- 必要なら `padding` / `min-height` 等を見直し、内容量に見合う高さへCompact化する。
- Responsive時の列数変更は今回の指摘対象に含めない。既存挙動を不用意に変更しない。

## 受入条件

1. Desktopの4-card layoutが維持される。
2. 各カードのタイトル・状態説明・アイコンが欠落しない。
3. 現状より明確に縦方向の占有量が小さくなる。
4. 文字切れや視認性低下を起こさない。
5. この修正だけを理由にResponsive layoutを再設計しない。

## 対象外

- 4列 → 2列への変更。
- Status文言の変更。
- Initial Setup全体の情報設計変更。
