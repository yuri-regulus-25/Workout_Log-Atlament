# DX-01 Android通常版と開発版の共存

## 概要

Android実機で、普段利用する安定したアプリと、開発・UT中のアプリを共存できるようにする。

## 現在確認されている問題

現在は1つのAndroid Appで検証している。

そのため開発・UT用Buildを端末へ導入すると、普段確認したい時にも開発途中の状態になり、機能が利用できない場合がある。

これは今後Android実機UTを継続する際の開発UX上の問題として記録する。

## 確定している要求

- 普段利用するAndroid Appと、開発・UT用Android Appを同一端末で共存可能にする。
- 開発中のBuildを導入することによって、普段利用する安定版を潰さない。
- v2.1.0 Data Recovery本体へ機能追加する要求ではない。

## 会話中に提示された実装候補

次は会話中に提示された案であり、現時点では確定仕様ではない。

- Androidの `applicationIdSuffix` 等を使用して別Application IDとする。
- 例:
  - `Atlament` — 普段利用する版
  - `Atlament Dev` — 開発・UT用
- アプリ名やアイコンも区別し、どちらを起動しているか視覚的に判別可能にする。

## 製造時に満たすべき状態

方式にかかわらず、最終的に次を満たすこと。

1. 1台のAndroid端末へ通常利用版と開発・UT版を同時Installできる。
2. 開発・UT版のInstall / Updateによって通常利用版が置換・削除されない。
3. 通常利用版を確認したい時に、開発中Buildの状態へ強制されない。

## 未確定事項
